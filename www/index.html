stun.evan-brass.net

This is a free STUN / TURN server

opensource

How to use

Adjust your WebRTC configuration to include this server:

const config = {
	iceServers: [{
		urls: [
			"turn:stun.evan-brass.net",
			"turn:stun.evan-brass.net?transport=tcp",
			"turns:stun.evan-brass.net:443?transport=tcp",
		],
		username: "guest",
		credential: "password"
	}]
};
